# FitBot - Interactive Fitness CLI Assistant

FitBot is a Python-based command-line interface (CLI) application designed to assist users with daily fitness metrics, including tailored water intake and protein requirement calculations based on body weight.

## Features

- **Water Intake Calculator**: Computes daily fluid requirements using body mass index principles.
- **Protein Goal Calculator**: Estimates optimal daily protein ranges (1.6g to 2.2g per kg) for physical training.
- **Fitness Knowledge Base**: Provides instant guidance on workout splits and basic nutrition guidelines.
- **Input Validation**: Ensures robust user experience through data type verification and error handling.

## Tech Stack

- **Language**: Python 3.x
- **Version Control**: Git / GitHub
